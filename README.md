# AI talent: train, retain, attract

Streamlit app answering: *Do countries that train AI researchers retain them, or does talent concentrate in a few destination countries?*
Audience: a government policy analyst.

Source: Ma & Yang (2026), Carnegie Endowment for International Peace, NeurIPS 2025 cohort (10,280 researchers with complete
career histories), workplaces observed 2026. Data extracted from the study's public Flourish charts; see `data/README.md`.

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Deploy: push to GitHub, then create an app on Streamlit Community Cloud with `app.py` as the entry point.
